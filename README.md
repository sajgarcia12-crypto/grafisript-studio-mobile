# Grafisript Studio Mobile

Standalone Android editor for the Grafisript language. This repository is independent from BlockForge.

## Included
- Native dark code editor
- Run button and output console
- Initial parser for `mostrar`, `mostrar_mensaje`, and prototype properties
- Save/open a local `.graf` file
- Original Grafisript Studio launcher icon

## Build APK
GitHub Actions builds a debug APK on pushes to `main` or manually from the Actions tab. Android SDK 35 and JDK 17 are used.

**Prototype:** This is the initial editor prototype, not the complete Grafisript interpreter yet. The original BlockForge code was not modified by this transfer.
